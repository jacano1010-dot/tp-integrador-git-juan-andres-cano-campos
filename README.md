
# Proyecto: Vida en el Campo y Paisajes de Montaña

## Descripción

Este proyecto consiste en una página web basada en texto que documenta las actividades rurales diarias, el cuidado de animales de granja, el mantenimiento de frutales y las caminatas por las montañas.

## Objetivo

Organizar y estructurar un repositorio digital utilizando Git y GitHub, aplicando un flujo de trabajo básico con ramas, commits, issues y pull requests mediante un contenido personal y descriptivo.

## Estructura del repositorio

* `README.md`: Explicación general del proyecto.
* `ENTREGA.md`: Registro del proceso de trabajo y comandos utilizados.
* `proyecto/`: Carpeta que contiene los archivos principales de la web.
  * `index.html`: Archivo principal con el contenido en texto.
  * `styles/styles.css`: Hoja de estilos para el diseño visual en carpeta aparte.
